# M2 Phase 1 · Short Paper 마일스톤

## 목표

Phase 1은 연구질문과 근거를 이용해 2페이지 상당의 Markdown 숏페이퍼를 반복 작성하고, 정적 검증과 연구자 승인을 거친 버전을 `K_short` 마일스톤으로 동결한다. LaTeX 생성과 정확한 페이지 수 판정은 범위에서 제외한다.

## 작업 흐름

1. 프로젝트 생성: 기존 연구질문 또는 연구자 입력에서 제목·연구질문을 확정하고 관련 지식카드를 선택한다.
2. 집필 명세: 대상 독자, 중심 주장, 글자 수 예산, 필수 섹션, 필수 카드, 작성 규칙, 연구자 미결정 사항을 저장한다.
3. 초안·보완: 명세와 지식카드를 LLM Task에 투영하고 기존 문장 검증, Revision To-do, M1 문헌 탐색 흐름으로 원고를 갱신한다.
4. 정적 검증: 원고 구조, 분량 예산, 문장 ID, 카드/인용 ID, 핵심 문장 근거, P0 To-do, 연구자 미결정 사항을 재현 가능한 규칙으로 검사한다.
5. Human Confirm: 연구자가 논증, 범위·한계, 근거·References를 각각 확인한다.
6. 동결: 검증에 사용한 원고·집필 명세·근거·References의 스냅샷을 `short_paper_frozen` 이벤트로 저장하고 편집을 읽기 전용으로 전환한다.
7. 재개: 새 근거 또는 범위 변경이 생기면 사유를 기록하여 동결을 해제하고 리비전 단계로 돌아간다.

## 작업실 UI

작업실의 첫 화면은 원고 탭이 아니라 프로젝트 개요다. 상단 진행판에서 다음 여섯 단계의 충족 여부와 현재 다음 행동을 항상 표시한다.

1. 연구질문·근거
2. 집필 명세
3. 초안 작성
4. 근거 보완·리비전
5. 마일스톤 검증
6. `K_short` 동결

사용자는 `프로젝트 개요`, `원고 작성·리비전`, `검증·승인·동결`, `변경 이력`의 네 화면을 전환한다. 프로젝트 개요는 연구질문·중심 주장·분량 예산, 현재 원고, 근거 자산, 우선 To-do와 최근 주요 변경을 한 화면에 요약한다. 상단의 `다음 작업 열기`는 미완료 상태에 따라 집필 명세, 문장 검증, Revision To-do, 정적 검증 또는 연구자 Confirm 화면으로 안내한다.

정적 검증 화면은 전체 검사표를 먼저 보여주지 않는다. 통과·동결 차단·확인 권고 건수를 요약하고, 남은 보완 작업을 우선 제시한다. 자동 검증을 통과한 경우에만 연구자 Confirm 입력과 동결 버튼이 활성화된다.

## 이벤트 계약

| 이벤트 | 역할 |
| --- | --- |
| `writing_spec_updated` | 버전이 있는 최소 집필 명세 저장 |
| `short_paper_validation` | 원고·명세 해시와 정적 검증 결과 저장 |
| `short_paper_frozen` | 연구자 승인 및 `K_short` 스냅샷 저장 |
| `short_paper_unfrozen` | 동결 해제 사유와 대상 마일스톤 저장 |

기존 `paper_project_events` 원장을 사용하므로 별도 테이블 마이그레이션은 없다. 동일한 초에 저장된 이벤트는 `created_at, rowid` 순으로 읽어 삽입 순서를 보존한다.

## 정적 검증 규칙

Blocker가 하나라도 있으면 동결할 수 없다.

- 원고와 제목 존재
- 필수 섹션 키워드 포함
- 공백 제외 글자 수가 명세의 최소·최대 예산 안에 존재
- 모든 문장 ID가 존재하고 중복되지 않음
- 연결된 지식카드가 현재 지식베이스에 존재
- 문장에 연결된 논문이 프로젝트 References에 존재
- 명세의 필수 카드가 본문 또는 Appendix에 반영됨
- 중심 주장·근거 문장이 지식카드 또는 등록 논문을 근거로 가짐
- 열린 P0 Revision To-do가 없음
- 연구자 미결정 항목이 없음

References 미등록과 중심 주장 미입력은 현재 Warning으로 표시한다. 실제 2페이지 여부는 렌더러가 없으므로 글자 수 예산으로만 관리하며, 정확한 페이지 수를 보장한다고 표시하지 않는다.

## 다음 단계 경계

Phase 2에서는 동결된 `K_short`를 기준으로 문장 Anchor, 확장 후보 Appendix, 하위 지식카드를 연결해 Full Paper 섹션 확장 워크스페이스를 구현한다. Phase 1의 동결본은 직접 덮어쓰지 않고, 동결 해제 또는 별도 Full Paper 브랜치의 입력으로만 사용한다.
